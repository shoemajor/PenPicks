PenPicks PWA

This is the installable web-app version.

To behave like a real iPhone app, these files must be hosted over HTTPS.
Once hosted:
1. Open the URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch PenPicks from the new icon.

Included:
- iPhone standalone/PWA support
- PenPicks home-screen icon
- offline shell caching
- local pick history
- voice-note prototype
- your three initial betting-pattern cards

Not connected yet:
- live NBA/WNBA game feed
- PrizePicks/Underdog live prop feed
- real confidence model
- push notifications
- cloud account/history
